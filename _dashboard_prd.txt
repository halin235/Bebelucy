 개요  (Overview)
본  문서는  ' 베베  센스  리포트 ' 의  전행  단계인  진입  대시보드 (Pre-Report Dashboard) 의
MVP
제품  스펙을  정의합니다 . 부모가  아침에  일어나  리포트를  확인하기  전 , 기기의  정상  작동
여부를  신뢰하고  공동  양육자와  원활하게  정보를  싱크할  수  있도록  정서적  안심감과  사용
편의성을  극대화하는  것을  목적으로  합니다 .
 핵심  제품  가치  (Core Value)
●
하드웨어  불신  해소 : 데이터  분석  결과에  앞서  센서  연동  상태를  투명하게  시각화하여
데이터의  신뢰도를  확보합니다 .
●  독박  육아  부담  완화 : 원클릭  공유  기능을  통해  부부  및  공동  양육자  간의  정보  격차를
해소하고  유기적인  공동  케어를  유도합니다 .
 핵심  기능  요구사항  (Functional Requirements)
3.1 디바이스  센서  점검  마일스톤
●  연동  상태  실시간  시각화 : 대시보드  최상단에  하드웨어 ( 베베루시  매트 / 클립 ) 의  센서가
어젯밤  데이터를  안전하게  수집했는지  단계를  마일스톤  형태로  노출합니다 .
●  체크  리스트  항목 : [ 기기  연결  상태 ] →  [ 실시간  호흡 / 심박  데이터  동기화 ] →  [ 수면  분석
알고리즘  가동 ].
●  UX 라이팅  규칙 : " 기기  고장  아닐까 ?" 라는  불안을  차단하기  위해  " 안전하게  수집
완료 (100%)" 등  명확한  안심  지표를  제공합니다 .
3.2 공동  양육자  공유  기능
●  원클릭  양육  파트너  연동 : 대시보드  내에  등록된  파트너 ( 배우자 , 베이비시터  등 ) 의
프로필  칩을  노출합니다 .
●  가이드  요약  송신 : [ 파트너에게  오늘  가이드  공유 ] 버튼  클릭  시 , 오늘  아기의  수면  상태
요약 ( 예 : " 오늘  루시는  원더윅스입니다 . 낮에  뒤집기  놀이를  도와주세요 !") 을  카카오톡
또는  인앱  알림으로  즉시  발송합니다 .
3.3 리포트  진입  게이트웨이  (CTA)
●  수면  분석  리포트  확인  버튼 : 마일스톤  점검이  끝나면  활성화되는  메인  액션  버튼입니다 .
